# Eco-Friendly Running Shoes Landing Page

This project is a **fully SEO-optimized landing page** built to rank for the keyword:

## Getting Started (Run Locally)

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/eco-running-shoes.git
```

### 2. Navigate into the Project Folder
cd seo-landing-page

### 3. Open the Project

You can run the project in any of these ways:

Option A: Open Directly
Double-click index.html

Option B: Use Live Server (Recommended)

If you're using VS Code:

Install the Live Server extension
Right-click index.html
Click "Open with Live Server"

## Deployment

This project is deployed using Netlify.

To deploy your own version:

Push your project to GitHub
Go to Netlify
Connect your repository
Click Deploy
